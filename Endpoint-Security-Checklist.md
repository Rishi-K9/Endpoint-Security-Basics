## Endpoint Security Checklist

## 1. Antivirus Protection
- Install trusted antivirus software.
- Keep antivirus updated.
- Perform regular system scans.

## 2. System Updates
- Enable automatic updates.
- Install security patches regularly.

## 3. Firewall Protection
- Enable Windows Firewall.
- Block unauthorized network connections.

## 4. Screen Locking
- Set a strong password or PIN.
- Enable automatic screen locking.
- Lock the screen when leaving the computer.

## 5. Additional Security
- Avoid suspicious links.
- Use strong passwords.
- Avoid unknown USB devices.

## Conclusion
Endpoint security protects computers from malware, cyber threats, and unauthorized access.

## Interview Questions and Answers

## 1. What is Endpoint Security?
Endpoint security protects devices such as laptops and desktops from cyber threats and unauthorized access.

## 2. What is EDR?
EDR stands for Endpoint Detection and Response. It monitors devices, detects suspicious activities, and helps security teams respond to threats.
